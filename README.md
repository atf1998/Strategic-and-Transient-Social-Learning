# Strategic-and-Transient-Social-Learning
This repository contains all materials associated with the publication, including the dataset, PsychoPy task-design code, and analysis scripts.  This work used a computational approach to analyze human behavioral data from a social learning task.

The Analysis Codes folder contains two Jupyter notebooks: Analysis and RL. All analyses reported in the publication are included in these files.

The Task Design folder contains three task files and one image folder. The 2 Arm file corresponds to the two-armed task completed by all participants. The Baseline Task file corresponds to the fully individual task without social information; in the publication, participants in this group are referred to as the Solo group. The Main Task file corresponds to the social learning task used for the SoLI and SoLU groups.

Finally, the Data folder contains all data collected from participants in the SoLI, SoLU, and Solo groups.
