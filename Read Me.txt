# Code and Data

This repository contains all materials associated with the publication, including the dataset, PsychoPy task-design code, and analysis scripts.

## Analysis Codes

The `Analysis Codes` folder contains three Jupyter notebooks. All analyses reported in the publication are included in these files.

- **Analysis.ipynb** – Behavioral analyses, statistical comparisons, and visualization of the results.
- **GLM.ipynb** – Mixed-effects analyses of choices, imitation, and confidence, including robustness checks.
- **RL.ipynb** – Reinforcement learning model fitting, model comparisons, and validation analyses.

## Task Design

The `Task Design` folder contains three PsychoPy task files and an image folder.

- **2arm.py** – The two-armed task completed by all participants.
- **Base-line task.py** – The fully individual task without social information. Participants in this condition are referred to as the **Solo** group in the publication.
- **main design.py** – The social learning task used for the **SoLI** and **SoLU** groups.
- **Images/** – The images and instructions displayed during the tasks.

## Data

The `Data` folder contains participant-level CSV files from the **SoLI**, **SoLU**, and **Solo** groups. Each group has separate `2 arm` and `4 arm` folders containing the corresponding task data. The files record trial-by-trial choices, outcomes, confidence ratings, response times, and, where applicable, social information.
